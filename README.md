# Omega Dental

Landing page for **Omega Dental** — a dental clinic in West Kazipara, Mirpur, Dhaka.

A single-file, dependency-free website (`index.html`) featuring:

- Bilingual UI (English / বাংলা) with a toggle, persisted in `localStorage`
- Services grid, treatment spotlight, and a searchable full price list
- Live treatment price estimator
- Free callback request form (client-side)
- Doctor profile, opening hours (today highlighted), FAQ accordion
- Sticky nav, mobile menu, WhatsApp float, scroll reveal animations
- SEO meta tags and responsive layout

## Run locally

It's a static page — just open `index.html` in a browser, or serve it:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```
